# One-off printed sheets

Single-use sheets for the workroom and the shop: shot lists, day plans, shopping lists.
Hand-written HTML on the same parchment base as the market kit, rendered the same way:

    cd tools/print-kit
    .\render.ps1 ..\shot-lists\<name>

⚠️ **The folder name is narrower than what is in it.** It began as shot lists for videos and
now also holds a day plan and a shopping list. Renaming it would break the paths in TASKS.md
and in the print-kit README, so it stays — **but do not assume a file here is about filming.**

Unlike `make-sheets/`, nothing here is meant to survive. These are printed, used, and thrown
away; **each one carries its date in the footer** so a stale sheet is obvious in the hand.

- **tiktok-rose-latte-cloud.html** — five shots, ~35s, three hooks, caption and tags.
- **todo-fri-sep-25.html** — the pack-day list before the Sep 26 / 27 markets.
- **shopping-holiday-fabric.html** — 8 fat quarters, 2 cuff plushes, interfacing, ~$40.
  ⚠️ **Written 2026-09-28 because the fabric library holds 76 prints and exactly TWO are
  festive**, and stockings are custom-only, so the customer chooses from the library.
  ⛔ **Fat quarters, never yardage** — sewing stops about Nov 7 and the move is Nov 25, so
  unsewn yardage is freight. The sheet lists what is already in the cupboard so nothing is
  bought twice, and notes that most of those are not in the library yet: photographing them
  adds range for nothing.
